# Publication checks

- All six game menus loaded and their start controls launched a game in desktop Chromium.
- No JavaScript page errors or external network requests were observed during those launch checks.
- Browser graphics and audio are generated by the games; external font stylesheet links were removed from this export.
- Exported text was scanned for common credential patterns, private-key blocks, credential assignments, personal email addresses, machine identifiers, private-network URLs and absolute local paths. No unresolved matches remained.
- Only allowlisted static game files, the two submitted prompts, metrics and public documentation are included. No symlinks, screenshots, configuration/session files, logs, dependency folders or source maps are included.
- Fresh Git history uses the public account name and GitHub no-reply email for both author and committer.

These are launch and publication checks, not a complete gameplay test or a mathematical guarantee against every possible defect. The original gameplay logic is preserved, including its bugs.
